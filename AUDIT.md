# netOP conversion audit

Audit date: 2026-09-03. Baseline: `1843454`. The authoritative algorithms were
relocated from `library_functions/` into the standard package tree without a
mathematical rewrite.

## API and source relationships

- `inst/API` is the explicit export allowlist. The installed namespace is
  tested against it, and the denylist covers validators, split workers,
  source-loading machinery, `_cpp` routines, dotted ECV helpers, and obsolete
  ECV/NCV wrapper names.
- Rcpp interfaces are generated by `Rcpp::compileAttributes()` and registered
  in `src/RcppExports.cpp:120-135`; dynamic symbol lookup is disabled.
- Package helper discovery now searches the calling namespace explicitly.
  Installed operation therefore does not depend on file source order.
- Canonical openings are tested for NETCROP block-model/RDPG/LSM and
  regularizer selection, ECV block-model/RDPG, and NCV block-model selection.

## Security and robustness findings

No critical or high-severity finding was identified.

### Medium: trusted-input requirement for resumable RDS files

`run_simulations()` reads a caller-selected existing RDS file when
`action = "resume"` (`R/01_basic_helpers.R:1013-1025`). R serialization should
not be treated as a safe interchange format for untrusted files. This is an
explicit local path supplied by the caller, not network input, and resumed
content is checked to be a list. Users should resume only files they created or
trust. Changing the storage format would break established simulation-result
compatibility, so behavior was preserved and the trust boundary documented.

### Low: caller-controlled large allocations

`read_network()` reads the selected edge-list and allocates an `n` by `n`
matrix (`R/04_network_generator.R:242-324` and subsequent construction).
Decomposition and path routines can likewise allocate quadratic output by
definition. Numeric dimensions, indices, finiteness, duplicates, and matrix
shape are validated; high-level algorithms expose conservative RAM preflight
reporting. There is no arbitrary global cap because valid research networks
vary widely. Callers should apply file-size and problem-size limits when
processing untrusted inputs.

### Low: interrupt latency in compiled graph traversals

The internal all-pairs BFS/Dijkstra loops allocate bounded queues and validate
matrix dimensions, finiteness, and nonnegative weighted edges
(`src/03_network_utils.cpp:29-120,157-211`), but do not poll for a user
interrupt inside every source-node loop. Extremely large path calculations may
therefore have delayed cancellation. The routines remain memory-safe for
validated R/Matrix inputs; adding interruption points is a future robustness
improvement, not a mathematical correction.

### Resolved: unintended edge-list overwrite

`write_network()` now rejects an existing path unless `overwrite = TRUE`
(`R/04_network_generator.R:135-153`). Tests cover rejection and explicit
replacement.

### Parallel cleanup and reproducibility

`uni_mclapply()` validates and caps worker counts, tags worker failures, and
falls back or stops according to policy. On future backends it records and
restores the caller's plan and the temporary renv environment setting
(`R/01_basic_helpers.R:175-255`). High-level algorithms avoid nested worker
oversubscription. Seed validation and deterministic seed offsets are exercised
by generator and model-selection tests.

### Native-code review

- Raw compiled routines are internal and inaccessible through `netOP::`.
- AUC input length, binary labels, and finiteness are checked before indexing
  (`src/02_math_helpers.cpp:20-84`). Procrustes dimensions are checked before
  Eigen operations (`src/02_math_helpers.cpp:110-119`).
- Dense and sparse adjacency builders validate shape, stored values, and
  nonnegative weighted edges before traversal (`src/03_network_utils.cpp:29-120`).
- The LSM accelerator checks all dimensions, finiteness, binary values,
  symmetry, zero diagonal, positive steps, and iteration count, and polls for
  interrupts (`src/05_embedders.cpp:35-68,73-114`).
- No shell, compiler, subprocess, download, runtime installation, or network
  call exists in package runtime code.

## Licensing and provenance

`LICENSE.note` and `inst/COPYRIGHTS` provide the file-level inventory. The ECV
portions of `R/x6_other_algos.R` derive from GPL (>= 2) CRAN randnet 1.0 by
Tianxi Li, Elizaveta Levina, Ji Zhu, and Can M. Le. The low-level block-model
implementation and isolated RDPG implementation were preserved from the
authoritative baseline; package conversion changed wrapper naming, namespace
integration, validation, and registration, not their mathematics. netOP is
therefore distributed under GPL (>= 2). The generated Rcpp interfaces and all
other package code are inventoried separately.

The concise `CODE_OF_CONDUCT.md` is original package prose informed by the
Contributor Covenant 2.1 and links to that CC BY 4.0 source; no full third-party
text is bundled.
